# Модели

По скрипту на модель. Каждый скрипт читает `data/sources_and_labels.jsonl` (или экзаменационный `data/exam/dataset.jsonl`)
и пишет предсказания в `predictions/` в общем формате (`predictions/README.md`).

Правила для всех моделей:

- **модель получает только изображение** — без группы источника и без эталона;
- **поворот фото:** картинку открываем через `ImageOps.exif_transpose(Image.open(...))`, иначе фото с поворотом в EXIF модель увидит не так, как его видели исполнители;
- **рамки** переводим в доли кадра (`left`, `top`, `width`, `height`), как в Контесте.

Зафиксировать для каждой модели: идентификатор и версию весов на Hugging Face, текстовый запрос, порог, преобразования
изображения, обработку рамок (NMS и т. п.), устройство (CPU/GPU).
