# Модели

По скрипту на модель. Каждый скрипт читает `data/photos.jsonl` (или экзаменационный `data/exam/dataset.jsonl`),
получает только изображение (без группы и без эталона) и пишет предсказания в `predictions/` в общем формате.

Зафиксировать для каждой модели: идентификатор весов на Hugging Face, текстовый запрос, порог, преобразования
изображения, обработку рамок (NMS и т. п.), устройство (CPU/GPU).
