# Проект review (проверка разметки)

Что положить сюда:
- `instruction.html` — инструкция ревьюерам (открывать в браузере);
- `settings.md` — экзамен, навык, порог допуска, контрольные примеры с проверенными ответами, перекрытие;
  как сделано, что автор разметки не проверяет свою работу;
  правило решения: принять / отправить на исправление / разобрать вручную;
- `raw/` — выгрузки вердиктов ревьюеров (как есть).
