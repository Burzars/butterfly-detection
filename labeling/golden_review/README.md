# Разбор спорных ответов и сборка golden set

Как из ответов разметчиков и вердиктов ревью получилась итоговая разметка `golden/golden.jsonl`.

## Правило

Каждое фото проверили два ревьюера. Фото **обязательно разбирает команда**, если выполнено хотя бы одно условие:

- ответ разметчика расходится с предварительной меткой датасета (бабочки есть / нет, сколько) — 12 фото;
- оба ревьюера ответили «неверно» — 6;
- ревьюеры разошлись (1:1) — 36;
- фото проверили только ревьюеры, позже заблокированные правилом контроля качества, — 20.

Одно фото может попасть сразу в несколько групп. Всего — **63 фото**. Остальные **337** фото (оба ревьюера «верно», расхождений нет) берутся с рамками разметчика без изменений.

Отклонённые и спорные ответы разбирали Анастасия и Михаил. По каждому из 63 фото они решали: оставить, исправить рамки, «бабочек нет» или «не уверен».

Арсений проверил их решения и разобрал 5 оставшихся случаев: 2 фото оба разобрали по-разному, ещё 3 исправления пришлось переделать. После этого он собрал итоговую разметку. Его решения передаются сборке через `--override`: они главнее, а заменённые решения сохраняются в журнале.

Рамки рисовали люди, модели в исправлениях не участвовали.

## Файлы

| Файл | Что это |
|---|---|
| `index.html`, `review_data.js` | Страница разбора: фото, рамки разметчика, вердикты ревью, кнопки решений, рисование рамок. Открывается в браузере |
| `prepare_review.py` | Готовит `review_data.js` из сырых ответов (`labeling/*/raw/`) |
| `golden_common.py` | Общие правила: чтение ответов и что обязательно разбирать |
| `build_golden.py` | Сборка golden set из ответов и решений, с проверками |
| `render_golden.py` | Картинки итога для проверки глазами (нужен Pillow) |
| `test_build_golden.py` | Тесты сборки |
| `decisions/` | Решения команды со страницы разбора: `misha.json`, `nastya.json`, `arsenii.json` |

Подсказки на странице («Подсказка Claude») — наблюдения ИИ-ассистента при просмотре: где, по-видимому, пропущена бабочка или рамка слишком свободная. Ошибки также искали сравнением с предварительной меткой датасета. Эту метку при сборе датасета ставила модель GPT-6 Astra (`data/README.md`). Решения принимала и рамки рисовала команда.

## Воспроизведение

Из корня репозитория:

```bash
# пересобрать golden set из сырых ответов и решений команды
python labeling/golden_review/build_golden.py \
  --decisions labeling/golden_review/decisions/misha.json labeling/golden_review/decisions/nastya.json \
  --override labeling/golden_review/decisions/arsenii.json

# проверки
python labeling/golden_review/test_build_golden.py
python eval/evaluate.py golden/golden.jsonl golden/golden.jsonl            # должно быть F1 = 1

# картинки: красное — разметчик, зелёное — итог (в viz/golden/)
python labeling/golden_review/render_golden.py
```

Сборка пишет в `golden/`:
- `golden.jsonl` — эталон;
- `golden_audit.jsonl` — по каждому из 400 фото: исходная разметка, вердикты ревью, причина разбора, решение, итог, кто решил, заменённые решения;
- `corrections.jsonl` и `corrections.md` — исправления с пояснениями.

Если хоть одно обязательное фото не разобрано или решение некорректно (исправление без пояснения, рамка за кадром, «не уверен», противоречие между файлами), сборка перечисляет замечания и ничего не пишет.

Открыть страницу разбора:

```bash
python -m http.server 8765 --bind 127.0.0.1
# в браузере: http://localhost:8765/labeling/golden_review/index.html
```

Можно открыть `index.html` и просто двойным щелчком: фото загружаются с iNaturalist, нужен интернет. Решения сохраняются в браузере, а кнопка «Сохранить файл решений» скачивает их в JSON.

## Проверки

- `build_golden.py` сам проверяет:
  - в golden ровно 400 фото датасета;
  - рамки в долях кадра внутри изображения;
  - от ответов разметчиков отличаются только фото с решением «исправлено» или «бабочек нет»;
  - ревьюерам были показаны ровно рамки разметчика;
  - никто не проверял сам себя.
- `test_build_golden.py` — 11 тестов, включая прогон через `eval/evaluate.py`.
- Ни у одного из 400 фото нет поворота в EXIF, поэтому рамки на странице совпадают с тем, что видели исполнители.
