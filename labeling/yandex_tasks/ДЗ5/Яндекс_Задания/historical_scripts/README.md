# Исторические скрипты

Назначение, порядок стадий и требуемые внешние входы перечислены в ../../../HISTORY.md (корень архива).

Копии сохранены для анализа реализации; бизнес-логика не переписывалась. В build_projects.py заменены только зависимости от старого репозитория ДЗ2/локального сертификата и чтение токена. Теперь общий API-клиент берётся из ../portable_runtime.py, а WORK указывает на родительский Яндекс_Задания. Все auth-данные поступают из окружения или исключённого из Git .env.

Не запускать старые миграции как последовательность обновления сегодняшних завершённых пулов. В архиве намеренно нет уже выгруженных командой инструкций, полных конфигураций и снимков до миграций. Некоторые подготовительные команды создают новые объекты либо изменяют существующие. Чтение кода и запуск тестов этих действий не выполняют.
