# Заметки о пакете в репозитории

Эта папка — пакет воспроизводимости Максима от 19.11.2026 (`README.md`, `HISTORY.md`, `AI_ASSISTANCE.md`). При переносе в репозиторий оставлено только то, что участвовало в итоговом процессе. Убраны:

- **16 фото** обучения и экзамена bbox (`ДЗ5/Локальная_разметка/additional_66/`). В репозитории картинок нет; ссылки на эти фото — в `ДЗ5/Проверка_эталонов/annotations_reviewed.json` (поле `image`) и в `ДЗ5/Локальная_разметка/dataset.json`. Внутри этих JSON остались исходные локальные пути `additional_66/...`: файл эталонов нельзя менять, его хеш записан в конфиге;
- **служебные файлы передачи архива** — контрольные суммы, диф упаковки, протокол проверки. В репозитории целостность обеспечивает git;
- **устаревший текст пояснений к эталонам**, который описывал ранний вариант обучения. Точные изменения эталонов — в `ДЗ5/Проверка_эталонов/changes.json`;
- **дубли конфигов интерфейсов** (`ui/*/template_builder_config.json`). Тот же конфиг лежит в `ui/*/view_spec.json`, поле `config`.

В документах Максима упоминания убранных файлов удалены, остальной текст не менялся.

Где что лежит:

- `ДЗ5/Яндекс_Задания/bbox_exam_control.py`, `bbox_training_control.py` — проверка обучения и экзамена bbox по IoU и выдача навыков; `configs/` — пороги и контрольная сумма эталонов; `state/` — решения, принятые при разметке;
- `ДЗ5/Яндекс_Задания/historical_scripts/` — создание проектов и пулов, загрузка заданий, перенос ответов bbox в review, миграции версий (`HISTORY.md`);
- `ДЗ5/Яндекс_Задания/ui/` — интерфейсы всех этапов; `qualification_ui/`, `review_learning_ui/` — исходники обучений;
- `ДЗ5/Проверка_эталонов/` — эталоны 66 примеров: исходная ручная разметка Максима, проверенная версия, список изменений, подготовка примеров для ревью;
- `ДЗ5/Локальная_разметка/server.py` — локальная страница, на которой рисовались эталоны.

Проверка из корня репозитория:

```bash
cd labeling/yandex_tasks/ДЗ5/Яндекс_Задания
python -m unittest test_bbox_exam_control test_bbox_learning     # 11 тестов, без сети и токена
python replay_bbox.py \
  --exam-assignments ../../../bbox/raw/pool_6870108_exam.jsonl \
  --training-assignments ../../../bbox/raw/pool_6870109_training.jsonl \
  --output /tmp/reproduced_scores.json         # пересчёт допуска: 8 из 9 на экзамене, 49 из 131 на обучении
```
