# Проект bbox (разметка рамок)

- `instruction.html` — инструкция исполнителям в том виде, в каком она стоит в проекте (выгрузка API 19.11.2026; открывать в браузере, картинки подгружаются с ImgBB);
- `settings.md` — этапы, цены, перекрытие, экзамен, навыки и порог допуска, контроль качества, почему выбраны такие значения, как прошла разметка;
- `raw/` — выгрузки сырых ответов исполнителей (как есть, без правок).

Отдельного пилота не было. Как проверяли интерфейс и инструкцию до запуска, написано в `settings.md`.
