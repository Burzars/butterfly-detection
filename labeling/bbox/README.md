# Проект bbox (разметка рамок)

Что положить сюда:
- `instruction.html` — инструкция исполнителям (открывать в браузере) с примерами: обычная бабочка, несколько бабочек, перекрытие, похожее насекомое, фото без бабочек;
- `settings.md` — цена, заданий на странице, перекрытие, экзамен, навык и порог допуска, правила контроля качества и почему выбраны такие значения;
- `pilot/` — выгрузка ответов пилота;
- `raw/` — выгрузки сырых ответов исполнителей (как есть, без правок).

## Что уже лежит в `raw/`

Выгрузка через API Яндекс Заданий 19.11.2026 (только чтение). Одна строка — одно задание исполнителя (assignment), поля как в API: `user_id` — обезличенный ID исполнителя, `tasks` — что показали, `solutions` — что ответили, `status`, время.

| Файл | Пул | Что внутри |
|---|---|---|
| `pool_6870107_main.jsonl` | 6870107, основной | 400 фото разметили 8 исполнителей; страница — 4 рабочих фото + 1 контрольное |
| `pool_6870108_exam.jsonl` | 6870108, экзамен | 10 попыток, допуск при 7 из 8 с IoU ≥ 0,75 |
| `pool_6870109_training.jsonl` | 6870109, обучение | бесплатное обучение, 8 фото; `first_answer` — первый ответ до показа эталона |

Рамки — `{"shape": "rectangle", "left", "top", "width", "height"}` в долях кадра.
