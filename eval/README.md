# Метрики

Скрипт метрик сравнивает файл предсказаний с `golden/golden.jsonl` так же, как Контест:
внутри фото — максимальное паросочетание рамок с IoU ≥ порога, TP/FP/FN суммируются по всем фото,
F1 = 2·TP / (2·TP + FP + FN).

Считаем: F1@0.5, precision, recall, F1@0.75, FP на фото без бабочек, число ошибок, время — на всём наборе и по группам.
Проверка скрипта: если подать эталон вместо предсказаний, должно получиться F1 = 1.

`leaderboard.md` — итоговая таблица (копия в корневом README).
