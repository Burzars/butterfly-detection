# Golden set

`golden.jsonl` — итоговая проверенная разметка всех 400 фото, формат в корневом README.
У каждого фото есть рамки или подтверждённое отсутствие бабочек (`"boxes": []`).

Как получена: исходная разметка → вердикты ревью → исправления (`labeling/corrections.jsonl`).
Формат исправлений:

    {"photo_id": 123, "before": [...], "after": [...], "reason": "пропущена вторая бабочка", "by": "человек"}

Если исправление предложила модель, в `by` пишем `"модель"`: это не независимая человеческая проверка.

`qa_check.md` — результаты ручной выборочной проверки: сколько фото просмотрено, найденные ошибки, как их нашли.
