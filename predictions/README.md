# Предсказания

Имя файла: `<модель>__<конфигурация>.jsonl`, например `gdino_tiny__butterfly_t0.35.jsonl`.
Сохраняем ответы всех запусков, включая неудачные эксперименты.

## Формат

Одна строка на фото:

```json
{"photo_id": 123, "boxes": [{"left": 0.1, "top": 0.25, "width": 0.3, "height": 0.5, "score": 0.83}], "error": null, "time_sec": 0.42}
```

- **Рамки в долях кадра, как в Контесте:** `left`, `top` — левый верхний угол, `width`, `height` — размеры (от 0 до 1). Если модель отдаёт пиксели или два угла, переводим в этот формат до сохранения.
- **`score` сохраняем.** По нему подбирается порог без повторного запуска модели. В файл для Контеста `score` и `time_sec` не попадают.
- **Пустой список и ошибка — разные вещи.** `"boxes": []` — модель обработала фото и бабочек не нашла. Если фото не загрузилось или модель упала, пишем `"boxes": null, "error": "причина"` и заносим случай в журнал ошибок. Подменять ошибку пустым списком нельзя.
- **`time_sec`** — время обработки одного фото.

`errors.log` — журнал технических ошибок: фото, причина, повторная попытка и её результат.
